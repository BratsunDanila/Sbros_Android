# Сброс

Android-приложение для мыслей, дел и личных планов. Запиши всё, что держишь в голове, обычным текстом или голосом — «Сброс» поможет разложить запись по местам.

**[Скачать APK](https://github.com/BratsunDanila/Sbros_Android/releases/latest)** · Android 8.0 и новее

## Как это работает

1. **Выгрузи мысли.** Можно написать несколько предложений или надиктовать запись, делая паузы.
2. **Получи предложения.** ИИ выделит дела, проекты и их шаги, события, идеи и личные записи.
3. **Проверь разбор.** Исправь названия, сроки и связи, убери лишнее или разбери запись вручную.
4. **Подтверди сохранение.** Только после этого предложения попадут в соответствующие разделы.

Исходный текст остаётся в истории сбросов. Его можно перечитать или удалить отдельно от созданных записей.

## Пять основных экранов

| Экран | Для чего он нужен |
|---|---|
| **Дела** | Одно действие в фокусе и остальные дела ниже. Свайп вправо выполняет дело, влево показывает следующее. Шаги одного проекта объединены в группы. |
| **Мысли** | Идеи и личные записи: поиск, избранное, редактирование и поиск записей по общим словам. Мысль можно явно превратить в дело. |
| **Сброс** | Ввод голосом или текстом, сохранение на потом и разбор с помощью ИИ. |
| **Календарь** | События и сроки дел. Срок задачи отображается в календаре без создания второго события. |
| **Обзор** | Проекты, ожидания, планы на будущее, материалы, выполненные дела, входящие и история сбросов. |

## Что ещё умеет приложение

- **Проекты со связанными шагами.** Каждый шаг — полноценное дело. Прогресс показывает выполненные шаги; завершение проекта подтверждается отдельно. Выполненные шаги и завершённые проекты можно раскрыть и вернуть в работу.
- **Совет по делу.** ИИ учитывает выбранное действие и контекст проекта. Совет ничего не добавляет в список автоматически.
- **Управление записями.** Редактирование, удаление с подтверждением и отмена удаления через уведомление.
- **Локальная работа.** Записи хранятся на устройстве. Для начала работы аккаунт не нужен.
- **Аккаунт и синхронизация.** По желанию записи можно перенести в аккаунт и синхронизировать между устройствами. Разные версии записи разрешаются через выбор пользователя.
- **Резервные копии.** Экспорт в файл и восстановление в локальное пространство без перезаписи текущих записей.
- **Оформление.** Светлая и тёмная темы, несколько цветовых палитр и шрифт Onest.

## Первый запуск

Установи APK из раздела [Releases](https://github.com/BratsunDanila/Sbros_Android/releases) и выбери «Начать без аккаунта» или войди в аккаунт для синхронизации.

Для ИИ-разбора добавь личный API-ключ **Token Harbor** в настройках ИИ. Используется модель `deepseek-v4.1-flash:free`; её доступность и лимиты определяются провайдером. Без ключа доступны ручные функции приложения. Разбор и облачная синхронизация требуют интернета; доступность голосового ввода зависит от службы распознавания Android.

Личный ключ хранится зашифрованным с использованием Android Keystore и не включается в облачную синхронизацию или резервную копию. При ИИ-разборе текст передаётся внешнему провайдеру после согласия пользователя. Файл экспортированной резервной копии содержит текст записей.

## Технологии и сборка

Нативное приложение на **Kotlin и Jetpack Compose**. Локальное хранение — **Room**, настройки — **DataStore**, фоновая синхронизация — **WorkManager**. Аккаунты и облачная база — **Supabase Auth / PostgreSQL**, голосовой ввод — **Android SpeechRecognizer**.

Открой проект в Android Studio с Android SDK 35 и выполни Gradle Sync. Для локальной работы настройки облака не обязательны. Пример конфигурации: [local.properties.example](local.properties.example). Настройка собственного Supabase описана в [supabase/README.md](supabase/README.md).

```powershell
.\gradlew.bat assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`. Для собственной подписанной release-сборки используй **Build → Generate Signed App Bundle / APK** в Android Studio и свой ключ подписи.
