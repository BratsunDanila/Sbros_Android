Ты реализуешь нативное Android-приложение «Сброс» (Kotlin + Jetpack Compose) по приложенному пакету. Прочитай AGENTS.md, README_START.md, все docs и референс reference/sbros_v14_clean.html ПОЛНОСТЬЮ перед написанием кода. Открой HTML, изучи интерактивность и сопоставь с reference/v14_all_screens.png.

Моя главная ценность — очень красивый, лёгкий интерфейс v14 clean. НЕЛЬЗЯ упрощать визуальную композицию, возвращать удалённые верхние подписи или заменить Android UI WebView. Внизу ровно 5 пунктов: Дела, Мысли, Сброс, Календарь, Обзор. Центральный микрофон вписан в линию панели, а не огромная FAB.

Стек: Kotlin, Jetpack Compose, Supabase Auth/Postgres/Edge Functions, Token Harbor через Edge Function, Android SpeechRecognizer. Нужны Welcome, вход, регистрация, управление сессией. Суть приложения — единый сброс текста/речи, серверное AI-предложение структуры, ручная правка карточек, явное подтверждение, атомарное сохранение исходника и результатов. Никаких автозадач из дневника.

Работай СТРОГО ПОЭТАПНО по docs/IMPLEMENTATION_PLAN.md. СЕЙЧАС ВЫПОЛНИ ТОЛЬКО ЭТАП 1: создай Android Studio проект, Compose UI пяти экранов, темы и навигацию с локальными фикстурами, onboarding визуально согласованный с v14, собери рабочую debug-сборку, проверь результат на эмуляторе и покажи снимки экранов. Перечисли оставшиеся расхождения с HTML. Только после моей проверки внешнего вида переходи к этапу 2.

Не выдумывай секреты, API модели и доступность служб транскрибации. Если окружение не содержит SDK/эмулятора, подготовь воспроизводимый проект и честно объясни ограничение, не заявляя, что APK собран.
