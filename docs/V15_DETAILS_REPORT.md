# v15: вложенные страницы, редакторы и SVG-иконки

Версия `0.2.1-demo-v15-details`, code 4. Исправлена неполная реализация интерактивных состояний HTML: прежде коллекции «Обзора» были упрощёнными шторками, задачи не открывали редактор, проекты и материалы были жёстко заданными строками.

## Поведение по HTML

Повторно проверены `shelves`, `projectView`, `taskRow`, `openEdit`, `openNew`, `openNote`, обработчики действий, CSS вложенных страниц/форм и все SVG в `reference/sbros_v15_full_list.html`.

| Действие | Реализация |
|---|---|
| Шесть коллекций «Обзора» | Полные страницы с заголовком, описанием, списком, кнопками назад/добавить; вкладка «Обзор» остаётся выделенной |
| Выбор проекта | Полная страница с градиентной карточкой результата, связанными делами и добавлением следующего шага |
| Главная карточка дела / стрелка строки | Редактор названия, места хранения, сферы; сохранение и отмена |
| Текст строки остальных дел | Выбор дела для главной карточки, как в v15; отдельная стрелка открывает редактор |
| Материал | Изменение названия и полного текста, удаление с отменой |
| Добавить в коллекции | Форма с выбором действия/проекта/ожидания/идеи на будущее/материала |
| Добавить из проекта | Новое дело связано с выбранным проектом |
| Входящие | Разобрать через центральный экран, явное ручное сохранение в мысли, удаление с отменой |
| Недельный обзор | Чек-лист и фактическая дата завершения |

Сами редакторы, входящие, настройки и недельный чек-лист остаются шторками: в HTML они используют `sheet`, в отличие от страниц коллекций. Редактирование проекта через карандаш/карточку результата добавлено по прямому запросу пользователя: исходный `projectView` отдельного редактора проекта не содержит. Удаление проекта оставляет все его дела, убирая связь; доступна отмена.

## Геометрия иконок и форм

У микрофона выявлена реальная ошибка конвертации: SVG допускает компактные флаги `a7 7 0 0014 0`, Android PathParser получает недостаточно параметров дуги. До исправления нативный тест на подключённом Xiaomi Android 16 воспроизвёл исключение; протокол сохранён в `screenshots/v15-detail-fix/icon-before-test.txt`. В Compose нижняя дуга пропадала.

Генератор теперь записывает `a7,7 0,0,0 14,0`, точно переводит скруглённые прямоугольники и окружности в дуги. Все 36 исходных иконок перегенерированы, для пяти пунктов навигации и центрального микрофона предусмотрены толщины CSS 1.8 и 1.55; у остальных 1.85. Регрессионный тест загружает все 42 ресурса штатным Android-парсером и отдельно проверяет пиксели нижней дуги.

Формы получили внешние подписи 11 sp/750, Onest 13 sp, поля с радиусом 15 dp, интервалы 16/7 dp, основную кнопку 49 dp и отмену 44 dp. В форме добавления первое поле без лишней подписи, кнопка с галочкой, как в `openNew`. Заголовки коллекций — 39 sp, радиусы строк — 20 dp, карточки проекта — 24 dp, верхние углы шторок — 30 dp. В нижней навигации убрана прямоугольная системная вспышка нажатия; плавное выделение сохранено. Статические начертания Onest сохранены.

UI-тест обнаружил и помог исправить перекрытие кнопки сохранения уведомлением от предыдущего добавления. При открытии следующего редактора старое уведомление закрывается; тест повторно открывает запись и проверяет сохранённый статус/полный текст.

## Данные и границы

Проекты, материалы и связи задач хранятся в общей локальной модели, сериализуются вместе с остальным состоянием через SavedStateHandle. При редактировании задачи сохраняются её источник, сложность и проект. При завершении ожидания/дела на будущее отмена восстанавливает прежний статус. Защита форм предотвращает двойное сохранение. Вручную перемещённая мысль содержит полный текст и `sourceText`; задачи из неё автоматически не создаются.

Это по-прежнему локальный демонстрационный этап. Постоянной БД, Supabase, ИИ, авторизации и распознавания речи нет; существующие сообщения о неподключённых функциях сохранены. SavedStateHandle не гарантирует сохранение после force-stop/новой сессии. Следующий этап не начат.

## Визуальная проверка и ограничения

Сопоставление выполнено по исходным CSS/JavaScript v15, исходному коллажу v14 (для общих экранов/стиля) и фактическим снимкам Android. Браузерный рендер v15 и попиксельное наложение не выполнялись; полного пиксельного совпадения не заявляем. Снимки вложенных экранов и редакторов находятся в `screenshots/v15-detail-fix/`.

Остаются различия платформ: реальные системные панели, растеризация текста, поведение клавиатуры, нативный выбор значения в списках и движение/высота шторки. Области нажатия увеличены для пальца. Длинные тексты и небольшая высота экрана требуют прокрутки. Дополнительная кнопка изменения проекта — отличие по запросу пользователя; у материала дополнительно доступны отмена и удаление с восстановлением. При добавлении из коллекции заранее выбрана её категория. Экран семантически похожих мыслей и история реальных разборов требуют последующих интеграций; они не выдают фиктивный результат.
