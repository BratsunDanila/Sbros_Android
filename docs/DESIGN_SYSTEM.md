# Визуальный контракт — НЕ ПЕРЕДИЗАЙНИВАТЬ

## Источник истины
`reference/sbros_v14_clean.html` + `reference/v14_all_screens.png`. Самостоятельно открой HTML и пройди навигацию, переключи тему/палитры, свайпай карточки, разбери текст, проверь шторки. Это визуальное ТЗ, не реализация на Android.

## Основная идентичность
- Светлый лавандовый, мягкие поверхности, ощущение простора.
- Крупные выразительные заголовки с точкой: `Дела.`, `Мысли.`, `Календарь.`, `Обзор.`.
- Один экран — одна понятная цель; никаких лишних шапок и «графиков продуктивности».
- Шрифтовой ориентир — **Onest** (подключён в веб-версии). Для Android использовать легально доступный шрифт с соответствующими весами либо максимально близкий fallback; не включать непроверенные лицензии.
- Скругления 14–28 dp, тонкие границы, сдержанная глубина. Никаких тяжёлых теней/неона/градиентов без соответствия макету.
- Минималистичные декоративные окружности/звёздочки (в разных местах по экрану) — делать Compose Canvas/vector, с уважением к настройкам анимаций.

Другие палитры доступны в исходном CSS (`data-palette=sage|clay|ocean`), тёмная тема — в `data-theme=dark`. Переноси токены, а не изобретай новые.

## Layout
- Пять пунктов внизу: Дела, Мысли, Сброс, Календарь, Обзор. Центральный микрофон чуть заметнее по **подложке и обводке**, но НЕ выступает вверх и НЕ становится огромной FAB.
- Контент должен учитывать `WindowInsets` (status/navigation bars), клавиатуру и узкие экраны.
- Убрать декоративную рамку «телефона» на настоящем Android; это только элемент десктопного веб-стенда.
- Не копировать вебовые псевдо-статусбар и боковую панель выбора палитр: Android получает настоящие системные панели; палитры доступны в настройках.
- **Не возвращать** верхние технические надписи `СБРОС / ...` и вторые слоганы над названиями, удалённые после v14. Основные заголовки/подзаголовки внутри экранов остаются.
- Разбивать контент на смысловые группы, не делать экран из 15 одинаковых карточек.

## Движение
- Экран: небольшое смещение/появление ~200–260 ms.
- Карточки: пружинящий свайп, уместный откат, понятная обратная связь при completion. Кнопки — лёгкое масштабирование при нажатии.
- Микрофон: тихое пульсирование/орбиты **только когда слушает** и деликатный idle-эффект без постоянной отвлекающей анимации.
- Шторки: мягкое появление снизу, фон слегка затемняется, возможность закрыть.
- При `animator_duration_scale=0` и `reduced motion` — без обязательных анимаций.

## Проверка пиксельного качества
1. Сделай screenshot Compose на 360x800 и 390x844 dp, сравни бок-о-бок с HTML.
2. Сравни заголовок, вертикальные расстояния, размер стопки дел, форму нижней панели и центрального микрофона.
3. Не допускай, чтобы контент оказывался под системной навигацией и клавиатурой.
4. Отдельно проверь dark mode и 4 цветовые схемы.
5. Удерживай исходные кнопки/экраны: если нативный UI визуально проще, чем референс, этап **не завершён**.
