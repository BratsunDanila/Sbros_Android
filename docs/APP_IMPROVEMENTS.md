# Улучшения после обзора проекта

## Изменения

- Подтверждённый сброс и новые результаты отправляются одной облачной транзакцией. Нужна миграция `005_atomic_analysis_sync.sql`; порядок установки указан в `DATABASE_SETUP.md`. Облако из этой сессии не изменялось.
- Отмена ИИ освобождает ожидающую корутину и закрывает активное HTTPS-соединение. Автоматического повторного платного запроса нет.
- Частые изменения черновика объединяются перед записью; сохранение и подтверждение остаются последовательными. Изменение одного черновика не запускает повторное декодирование всех записей.
- В «Мысли» карточки создаются по мере прокрутки. Для старых записей отображается настоящая дата в формате дд.мм.гггг вместо «На этой неделе».
- Временные флаги отправки форм не восстанавливаются как незавершённая отправка после пересоздания процесса.
- «Маленький первый шаг» предлагает одно действие через текущую модель `deepseek-v4.1-flash:free`. Название дела отправляется только по нажатию и после согласия на передачу текста. Подсказку можно исправить или написать вручную. Добавление требует отдельного нажатия; исходное дело сохраняется, новый шаг получает тот же проект, если он есть.
- «Похожие мысли» выполняет локальный поиск по общим словам, показывает совпадения и открывает найденные записи. Это не семантический поиск через ИИ.
- Рабочие модели переименованы и вынесены в `WorkspaceModels.kt`. Настройки, примеры и импорт старых снимков разделены по файлам. Имена Demo сохранены только как совместимые псевдонимы для прежних фикстур.
- Маршруты существующих сетевых фикстур приведены к v3 и атомарному подтверждению. Тесты не запускались.

## Резервная копия

«Настройки → Дополнительно» содержит экспорт и восстановление через системный выбор файла Android. Файл JSON включает записи выбранного пространства, черновик, сохранённые предложения ИИ и историю согласования. Токены сессии, API-ключи и настройки аккаунта в него не включаются.

Восстановление создаёт копии с новыми UUID в локальном пространстве, сохраняет связи, объединяет черновики и не перезаписывает существующие записи. Один и тот же файл повторно не импортируется. Некорректный файл отклоняется целиком. Максимальный размер — 16 МБ. Для последующего переноса восстановленных записей в аккаунт требуется обычное согласие на облачную синхронизацию. Сам файл содержит открытый текст личных записей; сохраняй его в выбранном личном хранилище.
