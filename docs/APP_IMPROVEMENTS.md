# Улучшения после обзора проекта

## Изменения

- Подтверждённый сброс и новые результаты отправляются одной облачной транзакцией. Нужна миграция `005_atomic_analysis_sync.sql`; порядок установки указан в `DATABASE_SETUP.md`. Облако из этой сессии не изменялось.
- Отмена ИИ освобождает ожидающую корутину и закрывает активное HTTPS-соединение. Автоматического повторного платного запроса нет.
- Частые изменения черновика объединяются перед записью; сохранение и подтверждение остаются последовательными. Изменение одного черновика не запускает повторное декодирование всех записей.
- В «Мысли» карточки создаются по мере прокрутки. Для старых записей отображается настоящая дата в формате дд.мм.гггг вместо «На этой неделе».
- Временные флаги отправки форм не восстанавливаются как незавершённая отправка после пересоздания процесса.
- «Совет по делу» даёт краткую рекомендацию через текущую модель `deepseek-v4.1-flash:free`, учитывая дело, его пояснение, цель проекта и до 20 связанных шагов с их статусами. Запрос выполняется по нажатию и после согласия на передачу текста. Совет доступен для чтения и копирования; новые дела или шаги проекта не создаются. Если контекст выбранного дела меняется, прежний запрос отменяется и совет сбрасывается.
- «Похожие мысли» выполняет локальный поиск по общим словам, показывает совпадения и открывает найденные записи. Это не семантический поиск через ИИ.
- Рабочие модели переименованы и вынесены в `WorkspaceModels.kt`. Настройки, примеры и импорт старых снимков разделены по файлам. Имена Demo сохранены только как совместимые псевдонимы для прежних фикстур.
- Маршруты существующих сетевых фикстур приведены к v3 и атомарному подтверждению. Тесты не запускались.
- Удаление доступно для дел и шагов в редакторе, а также для исходников в истории сбросов. У проектов, материалов, событий, мыслей и входящих используется общее подтверждение с описанием того, что сохранится. Удаления проходят через Room и существующую синхронизацию; действие можно отменить через уведомление. Карточка проекта объединяет сферу, статус, название, результат и прогресс.
- Фразы диктовки соединяются пробелом вместо искусственного нового абзаца. При временных ошибках службы выполняются до трёх повторов с задержкой, сохраняя уже распознанный текст. На Android 13+ передаётся `EXTRA_MASK_OFFENSIVE_WORDS=false`; поддержка зависит от службы. Приложение не запрашивает автоматическое форматирование и не вставляет знаки препинания по паузам. Точность распознавания, возможная пунктуация и системные звуки остаются зависимыми от службы Android; непрерывная запись без промежутков этим механизмом не гарантируется.
- Индикация диктовки — исходное плавное увеличение внешней окружности от громкости и небольшой индикатор уровня голоса. Крестик в поле ввода останавливает диктовку, сбрасывает отложенные ответы и очищает черновик вместе с привязкой к ранее открытому исходнику. Микрофон автоматически после очистки не запускается.
- Главная карточка «Дел» движется за пальцем один к одному. Свайп вправо выполняет дело, влево показывает следующее. Порог — 24% ширины карточки; быстрый свайп учитывается от 24 dp при скорости от 650 dp/с. Быстрое движение обратно перед отпусканием отменяет действие. Появлявшиеся надписи убраны: вместо них плавно усиливаются слабая заливка и обводка (зелёная вправо, акцентная влево). Достижение порога отмечается одним штатным тактильным откликом. Отменённый жест возвращает карточку на место; подтверждённый — уводит её за край перед сохранением действия. Повторные нажатия на уходящую карточку блокируются; при ошибке записи она возвращается. Единственное оставшееся дело нельзя перелистнуть влево.

## Резервная копия

«Настройки → Дополнительно» содержит экспорт и восстановление через системный выбор файла Android. Файл JSON включает записи выбранного пространства, черновик, сохранённые предложения ИИ и историю согласования. Токены сессии, API-ключи и настройки аккаунта в него не включаются.

Восстановление создаёт копии с новыми UUID в локальном пространстве, сохраняет связи, объединяет черновики и не перезаписывает существующие записи. Один и тот же файл повторно не импортируется. Некорректный файл отклоняется целиком. Максимальный размер — 16 МБ. Для последующего переноса восстановленных записей в аккаунт требуется обычное согласие на облачную синхронизацию. Сам файл содержит открытый текст личных записей; сохраняй его в выбранном личном хранилище.

## Границы

Проекты завершаются только явным действием пользователя; сценарий описан в `PROJECT_LIFECYCLE.md`, для облака нужна миграция 006. По просьбе пользователя не выполнялись сборка, тесты и создание скриншотов. Изменения требуют проверки на устройстве; готовность облачной части зависит от применения миграции.
