# Жизненный цикл проектов

- Новый проект без шагов показывает «Добавь первое действие».
- Прогресс считается по всем текущим шагам, включая ожидания и «когда-нибудь»: «Выполнено 2 из 5».
- После выполнения всех шагов появляется предложение завершить проект. Завершение требует отдельного нажатия; автоматически проект не закрывается.
- Удаление или перенос последнего незавершённого шага не создаёт это предложение. Пустой проект также не считается выполненным.
- Выполненные шаги свёрнуты в раздел «Выполнено · N». Нажатие на галочку возвращает шаг в следующие действия; на карточку — открывает редактор.
- Завершённые проекты находятся в сворачиваемом разделе внизу списка проектов. Из счётчика активных проектов в «Обзоре» они исключены.
- В завершённом проекте можно раскрыть выполненные шаги, отредактировать записи или вернуть проект в работу. Возврат шага в работу также открывает проект. Обычное редактирование названия или результата завершение сохраняет.
- Дата завершения показывается в формате дд.мм.гггг. Данные сохраняются в Room, резервной копии и облаке после применения `006_project_lifecycle.sql`.

Миграция 006 применяется после 005 через SQL Editor своего проекта Supabase. Она не удаляет данные и сохраняет атомарное подтверждение разбора. До обновления схемы новый клиент не отправляет изменения в прежний протокол. Инструкция: `DATABASE_SETUP.md`.

Сборка, тесты и скриншоты не запускались по просьбе пользователя. «Совет по делу» даёт рекомендацию с контекстом проекта и не добавляет новые шаги.
